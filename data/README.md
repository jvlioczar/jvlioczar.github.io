# A Biblioteca de Dados — BiblioVerse

Catálogo pesquisável das melhores fontes de dados e estatísticas do mundo: organizações internacionais, economia, institutos de estatística de cada país, índices globais, saúde, clima, animais, visualização e conceitos essenciais.

**Site:** https://biblioverse.org/data/ · parte do [BiblioVerse](https://biblioverse.org)

## Estrutura
- `index.html`: página e catálogo (gerados a partir do `catalogo.txt` local por `build.py`)
- `script.js` / `styles.css`: interface (busca, filtros, menu lateral, tema, PT/EN)
- `images/`, `favicon.ico`, `manifest.webmanifest`: ícones e app
- `CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml`, `404.html`: GitHub Pages e SEO
- A barra do topo vem de `https://biblioverse.org/superbar.js`
